# Smart File Organizer & Duplicate Finder

## Project Description
Smart File Organizer & Duplicate Finder is a Python-based desktop application that helps users organize files into different folders and identify duplicate files using SHA-256 hashing.

## Features
- Select a folder.
- Scan files and count file types.
- Organize files into Images, Documents, Videos, and Others.
- Detect duplicate files using SHA-256 hashing.
- Delete selected duplicate files while keeping the original.

## Technologies Used
- Python
- Tkinter
- SHA-256 Hashing
- Git & GitHub

## Requirements
- Python 3.x
- Windows / Python-supported operating system

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run:

```bash
py main.py
```
